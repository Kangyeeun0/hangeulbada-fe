# 한글바다 V2


## 1. 서비스 개요

### 한글바다는 학생들의 맞춤법 학습을 돕는 AI 기반 음운 규칙 받아쓰기 학습 서비스입니다.

<p style="text-align: left;">
   1. AI를 활용해 음운 규칙별 받아쓰기 문제를 자동으로 생성합니다. <br/>
   2. 전자기기 의존 없이 종이에 직접 쓰는 학습 방식을 제공합니다. <br/>
   3. 오답노트 관리를 통해 학생 개개인의 취약한 음운 규칙을 파악하고 반복 학습이 가능합니다.
</p>
